\# AI Hand Gesture Control



This project uses computer vision to recognize hand gestures and control system functions.



\## Features

\- Real-time hand gesture recognition

\- Uses camera input

\- Enables touchless interaction



\## Technologies Used

\- Python

\- OpenCV

\- MediaPipe



\## How to Run

1\. Install dependencies:

&#x20;  pip install opencv-python mediapipe

2\. Run the file:

&#x20;  python main.py
